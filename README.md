# Digital Library Search and Recommendation Engine

An industry-style Digital Library Search and Recommendation Engine implemented in C.

## Project Status

Currently under development as an 8-week algorithm and data structures project.

## Current Features

- Document representation using C structures
- Array-based document storage
- Formatted document display
- CSV dataset for library documents

## Planned Features

- Sorting and binary search
- Text pattern matching
- Search ranking
- Recommendation system
- Graph algorithms
- Dynamic programming
- Resource allocation
- Algorithm benchmarking
- Testing and performance analysis

## Language

C
